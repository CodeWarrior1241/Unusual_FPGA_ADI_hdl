# axi_ad9361 — Efinix Titanium device interface

Efinix port of the AD9361 LVDS device interface, sibling of `../polarfire/`.
Used by `projects/fmcomms2/ti375`.

One file: `axi_ad9361_lvds_if.v`. ADI's delineation/framing/tx-serialization
/ensm logic is verbatim from the PolarFire variant; the physical layer is
**absent by design** — on Titanium, LVDS buffers, the ×2 half-rate SERDES
(IDDR/ODDR equivalent), termination and delay elements live in the
configured periphery (Interface Designer), not in RTL. The periphery for
this design is generated by
`projects/fmcomms2/ti375/scripts/gen_interface.py`.

The module keeps the exact port list of the PolarFire variant so the shared
`axi_ad9361.v` needs no changes; the physical ports are repurposed at the
core–periphery boundary (l_clk enters on `rx_clk_in_p`, the PLL LOCKED on
`delay_clk`, and each `_p/_n` pair carries a 2-bit deserializer/serializer
word). The full mapping table and bring-up notes are in the file header and
in `projects/fmcomms2/ti375/README.md`.

There is no `common/` here: `ad_data_in/out/clk` have no Efinix equivalents
(replaced by periphery configuration), and the portable arithmetic helpers
(`ad_dcfilter.v`, `ad_mul.v`) are referenced from `../polarfire/common/`
to avoid divergence — they contain no vendor primitives and their
behavioral 17×17 multipliers infer Titanium DSP48 blocks as-is.
